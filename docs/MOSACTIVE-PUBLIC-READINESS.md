# МосАктив: публичный модуль

Web, Scanner и MosActive являются модулями одной платформы EventKAIT20 с общей
MySQL. Регистрация и отметка посещения создают исходные факты; после завершения
мероприятия SUPER_ADMIN или ORGANIZER проверяет ведомость, связывает участников
с контингентом и утверждает начисления по опубликованным правилам сезона.

## Публичные сведения

Любой посетитель без авторизации видит в рейтинге только фамилию с инициалами
и сумму баллов за мероприятия выбранного сезона. Поиск возвращает фамилию с
инициалами. Карточка студента дополнительно показывает учебную группу,
отделение/площадку из реестра и названия мероприятий с положительным итогом
начислений по каждому. Достижения, роль, результат, контакты, полное ФИО,
ручные корректировки и причины начислений не публикуются.

Импорт контингента автоматически создаёт публичные профили с нулём баллов.
SUPER_ADMIN может скрыть отдельный профиль. Сведения о согласии на публикацию
собираются вне платформы; интерфейса и API записи разрешённых полей больше нет.
Историческая таблица согласий сохраняется без удаления данных. Отдельное
согласие на регистрацию на мероприятие продолжает действовать.

## Что нужно перед реальным наполнением

1. Заполнить XLSX «Реестр контингента»: обязательны ФИО из двух или трёх слов
   и учебная группа. Дополнительные колонки сохраняются во внутренней базе;
   адрес площадки также показывается в публичной карточке. Импорт ограничен
   5000 строками и 5 МБ за раз, совпадения ФИО с группой проверяются вручную.
2. Настроить и проверить восстановление резервной копии MySQL. Текущий тариф
   Amvera не предоставляет управляемые резервные копии.
3. Настроить сезон, роли и уровни, опубликовать версию правил начисления и
   назначить её сезону. Без этого утверждение ведомости блокируется.
4. Для реальных регистраций настроить SMTP и точную версию действующего
   согласия на регистрацию; проверить работу Web и Scanner после развёртывания.
